Warm start tester

One button. It runs the Network layout of four test drops the usual way and with a warm start (5 runs each), measures how good each picture is, draws them side by side, then checks the cost of the onPiece option in the CSV reader. It takes about 3 to 5 minutes; the page is busy while it runs, so leave it alone. The drops are test files (big50k is the real drop; the other three are made-up).
