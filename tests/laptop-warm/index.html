What is measured

Four drops: big50k (the real one, 50,000 items), the same drop with its rows in random order, and two made-up drops with six communities (10,000 and 50,000 items). Today = netflow-engine 2.5.0, an early picture of the whole drop and then the final picture. New = the newest netflow-engine: a guess from the first half of the rows (timed apart, because it runs while the file is still being read), then one final build. Quick run: 3 builds each, today and new. Full run: 5 builds each and a third version with the extra fitting pass off. The versions take turns and the order flips every round. Stress, touching items and crossings are measured on the first picture of each.
