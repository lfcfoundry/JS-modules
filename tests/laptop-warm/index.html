Warm start tester

One button. It lays out four test drops with the Network layout three ways, 5 runs each: today (netflow-engine 2.5.0: an early picture of the whole drop, then the final picture), new (netflow-engine 2.6.0: a guess from the first half of the rows, made while the file is still being read, then one final build) and new, fastest (the same without the extra fitting pass). It then measures how good each picture is and draws them side by side. It takes about 2 to 4 minutes; the page is busy while it runs, so leave it alone. The drops are test files (big50k is the real drop; the other three are made-up).
