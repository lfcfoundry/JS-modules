Games

Modules for single-file browser games.

Saving and data safety

Keep a player's progress safe and let them move it between devices.

  • save-kit 1.0.0 · API 1: Safe localStorage saves, backup slot, checksummed copy-paste save codes with a size limit on what a paste may unpack to. global SaveKit · 11.1 KB · docs
  • tab-guard 1.0.0 · API 1: Keeps one open copy of a page in charge (Web Locks), so two tabs do not overwrite each other's saved data, and tells the game when the other copy closes. global TabGuard · 3.5 KB · docs

Device and browser adaptation

Make a game behave on slow phones, privacy-focused browsers and power-saving screens.

  • env-probes 1.1.0 · API 1: Detects privacy modes that round timers (including Firefox's 16.67 ms clock), scramble canvas read-back or block storage, and says what it found in plain words. global EnvProbes · 4.0 KB · docs
  • fx-governor 1.1.0 · API 1: Steps visual effects down when the device cannot keep up; never back up behind the player. global FxGovernor · 3.1 KB · docs
  • frame-kit 1.1.0 · API 1: Frame pacing for canvas games: even-dt smooths the frame time, quality-governor steps effects down and back up, job-pump spreads heavy jobs across frames, frame-meter shows frames a second, hitches and tap delay in plain words. global EvenDt, QualityGovernor, JobPump, FrameMeter · 18.0 KB · docs
  • slow-note 1.0.0 · API 1: Keeps a short note, only on the device, of the errors, slow taps and long frames a page had; copyable as plain text, nothing is sent anywhere. global SlowNote · 9.7 KB · docs

Controls

Let players hold a button, or play with a gamepad.

  • pad-nav 1.0.0 · API 1: Gamepad API to DOM focus: move through buttons, menus, sliders and drop-downs with a controller, no game code. global PadNav · 13.1 KB · docs
  • wake-keeper 1.0.0 · API 1: Keeps the screen awake only while a game wants it: released on pause, hidden tab and idle, asked again when allowed. global WakeKeeper · 4.9 KB · docs
  • back-close 1.0.0 · API 1: Makes the phone back swipe or back button close the top panel instead of leaving the page (CloseWatcher, with an opt-in history fallback for browsers without it). global BackClose · 2.4 KB · docs

First visit and grown-ups

Show a new player around, and keep small children away from the buttons that matter.

  • spotlight-tour 1.0.0 · API 1: A first-time tour: one dimmed layer, a bright window over the current part, Skip and Back, remembers who saw it and gives a finishing gift once. global SpotlightTour · 11.2 KB · docs

  • cartoon-3d-kit 1.0.0 · API 1: A written style guide plus demo for the soft, glossy cartoon 3D look done in plain CSS and SVG. no script, a style guide · docs

Game math

Size and packaging

Unpack a smaller file inside the game. The tools that pack it are under Tools.

  • lzma-decode 1.0.0 · API 1: Small readable LZMA1 decoder (ES5), tested against Python's lzma. Browsers can only unpack gzip and deflate natively. global lzmaDecode · 8.0 KB · docs
  • ppmd-decode 1.0.0 · API 1: A PPMd (7-Zip PPMd7) decoder in one ES5 function, about 6.6 KB packed. It unpacks web-page data about 10% smaller than LZMA, but about 4 times slower. PPMd is by Dmitry Shkarin; the public-domain code it follows is Igor Pavlov's, from 7-Zip. global ppmd7Decode · 25.6 KB · docs

Files, charts and simulation

Open zip and Excel files safely, draw flow charts, write animated GIFs and simulate random walkers.

  • gif-writer 1.0.0 · API 1: Writes animated GIFs from canvas pictures with one shared palette, storing only the pixels that changed (about 6.8 times smaller than gifenc on a mostly still animation). global GifWriter · 15.9 KB · docs
  • zip-open 1.0.0 · API 1: Opens .zip and Excel .xlsx files safely: limits counted on what really unpacks, so a zip bomb stops at the limit with a plain-words note. global ZipOpen · 25.5 KB · docs
  • river-layout 1.0.0 · API 1: Lays out a flow chart (Sankey) from a plain list of links, with about half the weighted crossings of d3-sankey on the charts measured, backward links drawn instead of crashing, and an SVG drawer. global RiverLayout · 26.3 KB · docs
  • walker-sim 1.0.0 · API 1: Simulates random walkers on a network with seeded, repeatable runs, 16 random-number distributions, 95% ranges and the exact odds to check against (about 1.75 million walkers a second). global WalkerSim · 37.9 KB · docs

Story editor

Packages for interactive stories, kept with the Story Editor they are cut from (source). Each is MIT-licensed, has no dependencies, and runs in Node 18+ or a browser.

Story data

Create, clean, import and save stories in one shared file format.

  • story-format: Create, clean, search, import and export interactive stories as JSON, with a JSON Schema. Twine import lives in twine-import.
  • twine-import: Reads Twine stories (Twine 2 HTML, Twee 3, Twine 1) and turns SugarCube and Harlowe code into rules, with a plain-words report.
  • story-outline: Turns an indented outline into pages and choices, or into a whole branching story.
  • story-diff: Says in plain words what one edit did to a story, such as "Add page “The Cellar”".

Checking

Find dead ends and endings nobody can reach before a reader does.

  • story-check: Exact checker for branching stories with items, numbers and dice: dead ends and endings no player can reach.

Drawing

See a story's shape: maps of its pages and simulated readers.

  • story-map: Layered, arc and matrix drawings of a story graph (SVG) and seeded simulated players.

Playing and building

Turn a story into a game, or play it from code or a terminal.

  • story-player: Build one offline HTML game from a story, or play a story from code or a terminal.

Tools

For building and testing. They are not shipped inside a game or story.

For games

Size and packaging

Pack a finished one-file game into a smaller file.

  • lzma-pack 1.0.0 · API 1: Packs one HTML file into a smaller self-unpacking file with LZMA and a hash check (Python 3 standard library).
  • ppmd-pack 1.0.0 · API 1: Packs one HTML file into a self-unpacking file with PPMd, the 7-Zip text compressor (PPMd by Dmitry Shkarin; public-domain code by Igor Pavlov, 7-Zip). Pure Python; pays off above about 60 KB of compressed data.
  • single-file-tools 1.1.0 · API 1: Font subsetting, safe inline-SVG tightening and a Zopfli self-extracting packer for one-file games.

Testing

Test a game by playing it at random, shrinking any failure to a short replay, and by counting what it draws.

  • fuzz-kit 1.1.0 · API 1: Seeded, reproducible random-input fuzzer engine with weighted operations, invariants, liveness checks and failure shrinking; Playwright and Puppeteer runners with real input and CPU throttling; stock-Firefox recipe; test-hook stripper.
  • canvas-probe 1.1.0 · API 1: Test-build counter for canvas 2D games: calls per frame, save/restore leaks, overhanging drawImage sources, draws below half size, style-write repeats, painted area.
  • storage-probe 1.1.0 · API 1: Page that tells you in plain words whether copies of a page saved in different folders share their saved data, see each other's writes and locks; one button, copyable report.
  • firefox-stand-in 1.0.0 · API 1: Runs a Playwright-for-Python test in stock Firefox (through Selenium and geckodriver) without rewriting it; says plainly which calls it supports and stops with a clear message on the rest.
  • webkit-driver 1.0.0 · API 1: Drives WebKitGTK or GNOME Web from Node with no dependencies, using the call names of Playwright and Puppeteer (goto, evaluate, waitForFunction, mouse, keyboard, screenshot, console errors), so a test written for them can also run in WebKit.
  • test-isolation 1.0.0 · API 1: Puts a prefix in front of every localStorage key on a test page, so a speed test or random-play run never touches the real saved game.
  • speed-lab 1.0.0 · API 1: One-button speed test run on the device: compares your page with parts switched off, keeps the scene in view and uncovered, and says the answer in plain sentences with a copyable table.

For the story editor

Size and packaging

Pack a finished story page into a smaller page.

  • zip-page: Wrap a finished HTML page into a smaller page that unzips itself, with a pure-JS inflater fallback.

Testing

Run tests on stock Firefox, generate random stories and keep two implementations in step.

  • qa-kit: Tiered test runner and a Playwright-style API over WebDriver BiDi for stock Firefox; seeded random-story generator.
  • contract-kit: A guide and a small helper for keeping two implementations of one rule set from drifting apart: seeded random inputs, a side-by-side comparison, a field table and a time limit.

Working with an AI helper

A written process for a person and an AI assistant building software together.

  • ai-collab-kit: A written process and templates for a person and an AI assistant building software together.
For researchers and AI helpers: modules.json (machine-readable, with side and category for every entry), llms.txt, AGENTS.md and the task board.
Test browsers: Firefox 158, ungoogled Chromium 155 and WebKitGTK 2.52.6 (Linux); results name the exact version, and every module's README and changelog entry says which of them tested that release. Not yet checked: real phones and Safari itself.
