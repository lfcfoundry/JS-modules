Modules & Tools (38)

Small pieces for single-file games and apps, and the tools that build and test them. Tools are not shipped inside a game.

Device and browser adaptation

Make a game behave on slow phones, privacy-focused browsers and power-saving screens.

  • env-probes 1.1.0 · API 1: Detects privacy modes that round timers (including Firefox's 16.67 ms clock), scramble canvas read-back or block storage, and says what it found in plain words. global EnvProbes · 16.2 KB · docs
  • frame-kit 1.2.1 · API 1: Frame pacing for canvas games: even-dt smooths the frame time, quality-governor steps effects down and back up, job-pump spreads heavy jobs across frames, frame-meter shows frames a second, hitches and tap delay in plain words. global EvenDt, QualityGovernor, JobPump, FrameMeter · 38.9 KB · docs
  • field-report 1.0.2 · API 1: Two hidden buttons for a game or app: five taps in a corner open a panel that saves a speed report (start-up, frames a second, slowest frames, heavy tasks, plain verdict) and an error log, as small Markdown files. No network. global FieldReport · 21.3 KB · docs
  • fx-governor 1.1.1 · API 1: Steps visual effects down when the device cannot keep up; never back up behind the player. global FxGovernor · 6.2 KB · docs
  • image-decode 1.2.0 · API 1: Loads PNG, JPEG, WebP and AVIF pictures so the page does not freeze when they are first drawn: picks the right off-thread way for each browser, loads a list in order, and tells whether the browser can read WebP or AVIF. global ImageDecode · 20.6 KB · docs
  • slow-note 1.0.0 · API 1: Keeps a short note, only on the device, of the errors, slow taps and long frames a page had; copyable as plain text, nothing is sent anywhere. global SlowNote · 9.7 KB · docs

Games - Testing

Test a game by playing it at random, shrinking any failure to a short replay, counting what it draws and driving real browsers.

  • canvas-probe 1.1.0 · API 1: Test-build counter for canvas 2D games: calls per frame, save/restore leaks, overhanging drawImage sources, draws below half size, style-write repeats, painted area.
  • firefox-stand-in 1.0.0 · API 1: Runs a Playwright-for-Python test in stock Firefox (through Selenium and geckodriver) without rewriting it; says plainly which calls it supports and stops with a clear message on the rest.
  • fuzz-kit 1.3.3 · API 1: Seeded, reproducible random-input fuzzer engine with weighted operations, invariants, liveness checks and failure shrinking; Playwright and Puppeteer runners with real input and CPU throttling; stock-Firefox recipe; test-hook stripper.
  • speed-lab 1.1.1 · API 1: One-button speed test run on the device: compares your page with parts switched off, keeps the scene in view and uncovered, and says the answer in plain sentences with a copyable table.
  • storage-probe 1.1.0 · API 1: Page that tells you in plain words whether copies of a page saved in different folders share their saved data, see each other's writes and locks; one button, copyable report.
  • test-isolation 1.1.0 · API 1: Puts a prefix in front of every localStorage key on a test page, so a speed test or random-play run never touches the real saved game.
  • webkit-driver 1.4.0 · API 1: Drives WebKitGTK or GNOME Web from Node with no dependencies, using the call names of Playwright and Puppeteer (goto, evaluate, waitForFunction, mouse, keyboard, screenshot, console errors), so a test written for them can also run in WebKit.

Size and packaging

Open zip and Excel files safely, and pack a finished page into a smaller file that unpacks itself.

  • lzma-decode 1.3.0 · API 1: Small readable LZMA1 decoder (ES5), tested against Python's lzma. Browsers can only unpack gzip and deflate natively. global lzmaDecode · 22.2 KB · docs
  • lzma-pack 2.0.0 · API 2: Packs one HTML file into a smaller self-unpacking file with LZMA and a hash check (Python 3 standard library).
  • pcodec-js 1.6.0 · API 1: Pcodec for web pages: unpacks (and optionally packs) big lists of numbers in a browser, one file, same bytes as any other Pcodec. The unpack-only file is 68 KB gzipped (the other JavaScript build of Pcodec is 324 KB), streams a 4,000,000-number file in 6.8 MB of memory, and WebAssembly is required (no plain-JavaScript backup). global PcodecJS · 103.9 KB · docs
  • ppmd-decode 1.3.0 · API 1: A PPMd (7-Zip PPMd7) decoder in one ES5 function, about 6.6 KB packed. It unpacks web-page data about 10% smaller than LZMA, but about 4 times slower. PPMd is by Dmitry Shkarin; the public-domain code it follows is Igor Pavlov's, from 7-Zip. global ppmd7Decode · 45.3 KB · docs
  • ppmd-pack 2.0.0 · API 2: Packs one HTML file into a self-unpacking file with PPMd, the 7-Zip text compressor (PPMd by Dmitry Shkarin; public-domain code by Igor Pavlov, 7-Zip). Pure Python; pays off above about 60 KB of compressed data.
  • zip-open 1.3.0 · API 1: Opens .zip and Excel .xlsx files safely: limits counted on what really unpacks, so a zip bomb stops at the limit with a plain-words note. global ZipOpen · 32.1 KB · docs

Story editor packages (10)

Packages for interactive stories, kept with the Story Editor they are cut from (source). Each is MIT-licensed, has no dependencies, and runs in Node 18+ or a browser.

Story data

Create, clean, import and save stories in one shared file format.

  • story-diff: Says in plain words what one edit did to a story, such as "Add page “The Cellar”".
  • story-format: Create, clean, search, import and export interactive stories as JSON, with a JSON Schema. Twine import lives in twine-import.
  • story-outline: Turns an indented outline into pages and choices, or into a whole branching story.
  • twine-import: Reads Twine stories (Twine 2 HTML, Twee 3, Twine 1) and turns SugarCube and Harlowe code into rules, with a plain-words report.

Story validation

Find dead ends and endings nobody can reach before a reader does.

  • story-check: Exact checker for branching stories with items, numbers and dice: dead ends and endings no player can reach.

Story flow

See a story's shape: maps of its pages and simulated readers.

  • story-map: Layered, arc and matrix drawings of a story graph (SVG) and seeded simulated players.

Story build and distribute

Turn a story into a game, or play it from code or a terminal.

  • story-player: Build one offline HTML game from a story, or play a story from code or a terminal.

Story packaging

Pack a finished story page into a smaller page.

  • zip-page: Wrap a finished HTML page into a smaller page that unzips itself, with a pure-JS inflater fallback.

Story testing

Run tests on stock Firefox, generate random stories and keep two implementations in step.

  • contract-kit: A guide and a helper (about 7.2 KB minified) for keeping two implementations of one rule set from drifting apart: seeded random inputs, a side-by-side comparison (also for async functions), shrinking a failing input to a small one, a field table and a time limit; runs in browsers too.
  • qa-kit: Tiered test runner and a Playwright-style API over WebDriver BiDi for stock Firefox; seeded random-story generator.
