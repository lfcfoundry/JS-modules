Games

Modules for single-file browser games.

Saving and data safety

Keep a player's progress safe and let them move it between devices.

  • save-kit 1.0.0 · API 1: Safe localStorage saves, backup slot, checksummed copy-paste save codes with a size limit on what a paste may unpack to. global SaveKit · 11.1 KB · docs
  • tab-guard 1.0.0 · API 1: Keeps one open copy of a page in charge (Web Locks), so two tabs do not overwrite each other's saved data, and tells the game when the other copy closes. global TabGuard · 3.5 KB · docs

Device and browser adaptation

Make a game behave on slow phones, privacy-focused browsers and power-saving screens.

  • env-probes 1.1.0 · API 1: Detects privacy modes that round timers (including Firefox's 16.67 ms clock), scramble canvas read-back or block storage, and says what it found in plain words. global EnvProbes · 4.0 KB · docs
  • fx-governor 1.0.0 · API 1: Steps visual effects down when the device cannot keep up; never back up behind the player. global FxGovernor · 3.1 KB · docs
  • frame-kit 1.0.0 · API 1: Frame pacing for canvas games: even-dt smooths the frame time, quality-governor steps effects down and back up, job-pump spreads heavy jobs across frames, frame-meter shows frames a second, hitches and tap delay in plain words. global EvenDt, QualityGovernor, JobPump, FrameMeter · 18.0 KB · docs

Controls

Let players hold a button, or play with a gamepad.

  • hold-press 1.0.0 · API 1: Hold-to-repeat for buttons that survives Android Chrome pointercancel. global HoldPress · 6.2 KB · docs
  • pad-nav 1.0.0 · API 1: Gamepad API to DOM focus: move through buttons, menus, sliders and drop-downs with a controller, no game code. global PadNav · 13.1 KB · docs
  • wake-keeper 1.0.0 · API 1: Keeps the screen awake only while a game wants it: released on pause, hidden tab and idle, asked again when allowed. global WakeKeeper · 4.9 KB · docs
  • back-close 1.0.0 · API 1: Makes the phone back swipe or back button close the top panel instead of leaving the page (CloseWatcher, with an opt-in history fallback for browsers without it). global BackClose · 2.4 KB · docs

Looks and effects

Curtains, flying elements, lettering and 3D-looking sprites, plus a written style guide.

  • stage-curtains 1.0.0 · API 1: Velvet stage curtains that slide shut over a page, then fly open. global StageCurtains · 19.2 KB · docs
  • fly-to-mini 1.1.0 · API 1: A big element scrolls away and a copy flies to its sticky mini version (and back). global FlyToMini · 5.5 KB · docs
  • sticker-text 1.0.0 · API 1: Die-cut sticker lettering in plain CSS text-shadow rings, no images. global StickerText · 4.0 KB · docs
  • sprite-baker 1.2.0 · API 1: Tiny software 3D rasterizer that bakes shaded sprites to canvases once at load, or one frame per tick; also makes silhouette masks and packs sprite sheets. global SpriteBaker · 32.7 KB · docs
  • cartoon-3d-kit 1.0.0 · API 1: A written style guide plus demo for the soft, glossy cartoon 3D look done in plain CSS and SVG. no script, a style guide · docs

Game math

The numbers behind idle and clicker games.

  • idle-core 1.0.0 · API 1: Tested maths for idle/clicker games: costs, buy-many and buy-max, milestones, away income, boost queue, number format. global IdleCore · 6.6 KB · docs

Size and packaging

Unpack a smaller file inside the game. The tools that pack it are under Tools.

  • lzma-decode 1.0.0 · API 1: Small readable LZMA1 decoder (ES5), tested against Python's lzma. Browsers can only unpack gzip and deflate natively. global lzmaDecode · 8.0 KB · docs
  • ppmd-decode 1.0.0 · API 1: A PPMd (7-Zip PPMd7) decoder in one ES5 function, about 6.6 KB packed. It unpacks web-page data about 10% smaller than LZMA, but about 4 times slower. PPMd is by Dmitry Shkarin; the public-domain code it follows is Igor Pavlov's, from 7-Zip. global ppmd7Decode · 25.6 KB · docs

Story editor

Packages for interactive stories, kept with the Story Editor they are cut from (source). Each is MIT-licensed, has no dependencies, and runs in Node 18+ or a browser.

Story data

Create, clean and save stories in one shared file format.

  • story-format: Create, clean, import and export interactive stories as JSON, with a JSON Schema.

Checking

Find dead ends and endings nobody can reach before a reader does.

  • story-check: Exact checker for branching stories with items, numbers and dice: dead ends and endings no player can reach.

Drawing

See a story's shape: maps of its pages and simulated readers.

  • story-map: Layered, arc and matrix drawings of a story graph (SVG) and seeded simulated players.

Playing and building

Turn a story into a game, or play it from code or a terminal.

  • story-player: Build one offline HTML game from a story, or play a story from code or a terminal.

Tools

For building and testing. They are not shipped inside a game or story.

For games

Size and packaging

Pack a finished one-file game into a smaller file.

  • lzma-pack 1.0.0 · API 1: Packs one HTML file into a smaller self-unpacking file with LZMA and a hash check (Python 3 standard library).
  • ppmd-pack 1.0.0 · API 1: Packs one HTML file into a self-unpacking file with PPMd, the 7-Zip text compressor (PPMd by Dmitry Shkarin; public-domain code by Igor Pavlov, 7-Zip). Pure Python; pays off above about 60 KB of compressed data.
  • single-file-tools 1.0.0 · API 1: Font subsetting, safe inline-SVG tightening and a Zopfli self-extracting packer for one-file games.

Testing

Test a game by playing it at random, shrinking any failure to a short replay, and by counting what it draws.

  • fuzz-kit 1.0.0 · API 1: Seeded, reproducible random-input fuzzer engine with weighted operations, invariants, liveness checks and failure shrinking; Playwright and Puppeteer runners with real input and CPU throttling; stock-Firefox recipe; test-hook stripper.
  • canvas-probe 1.0.0 · API 1: Test-build counter for canvas 2D games: calls per frame, save/restore leaks, overhanging drawImage sources, draws below half size, style-write repeats, painted area.
  • storage-probe 1.0.0 · API 1: Page that tells you in plain words whether copies of a page saved in different folders share their saved data, see each other's writes and locks; one button, copyable report.

For the story editor

Size and packaging

Pack a finished story page into a smaller page.

  • zip-page: Wrap a finished HTML page into a smaller page that unzips itself, with a pure-JS inflater fallback.

Testing

Run tests on stock Firefox and generate random stories.

  • qa-kit: Tiered test runner and a Playwright-style API over WebDriver BiDi for stock Firefox; seeded random-story generator.

Working with an AI helper

A written process for a person and an AI assistant building software together.

  • ai-collab-kit: A written process and templates for a person and an AI assistant building software together.
