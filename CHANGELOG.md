This page lists where each one stands and the changes made since version labels began on 2026-10-16. Older history is in each module's changelog under "Before version labels". The full details (numbers, test runs, browsers) are kept privately by the maintainers.

How to read a label: `1.2.3 · API 1`. The API number goes up only when someone using an older copy could be affected; see [tools/versions/README.md](tools/versions/README.md).
