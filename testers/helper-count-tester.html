What is measured

Three jobs, each run with the module's old default helper count and with the new one, on the same data: text-columns reading a 40 MB made-up CSV in parallel, lfc-pack packing 30 MB of made-up NDJSON in parallel, and graph-walk's betweenness on a 6,000-item made-up network. Each round closes the helpers, makes one warm-up call, then times one call; the two counts take turns and swap order every round (9 rounds in Quick, 21 in Full). The data is made up because this compares a module with itself; the answers are the same either way. A count the device gives the same both ways is skipped.
