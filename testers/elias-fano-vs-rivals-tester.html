What is measured

Real lists (sorted row numbers: every value of a column of retail, federal-assistance, SEC or FHIR files is a list of the rows that hold it). FHIR is the generated-patient training set (100 patients). Short lists have 2 to 63 values, mid 64 to 1,023, long 1,024 or more; each set contributes up to 600 long, 1,500 mid and 1,500 short lists picked at random. Races: decode every list of a set into your own array; 50 lookups per list (first value at or above); 300 random pairs intersected; size of all lists. Ours is the tiny kind for short lists, block lists with arrays for mid-length lists (flat lists for lookups) and flat lists for long lists (decode and lookups; block lists intersect). Both sides do the same job, take turns with the order swapped every round, and answers are checked equal before each race. Rivals: roaring-wasm 1.1.0 (portable bitmap), a BP128-style and a Stream VByte-style coder (our own WebAssembly prototypes, measure only), binary interpolative coding (size only), varint gaps (FastIntegerCompression 0.1.0, size only) and a plain Uint32Array (4 bytes a value, binary search). The lists are random samples; they were made on a cloud machine and are used for testing only. Quick run uses four of the five sets and the closest rivals only.
