# grown-ups-door changelog

What changed in each version, newest first, in plain words. The numbers are explained in [tools/versions/README.md](../../tools/versions/README.md): the API number goes up only when someone using an older copy could be affected.

## 1.0.0 · API 1 · 2026-10-17
New module, cut from Apple Press's Grown-ups door. Buttons and links you point it at ask for a short task first: hold a round button for 3 seconds, then drag the item into the target (or tap the item, then the target; the keyboard works). After a pass the controls stay open for 2 minutes. It is a speed bump for small children, not security. Changed from the Apple Press original, which guarded three fixed controls with a fixed apple and basket: the guarded controls (`guard`), the art, every sentence, the hold time and open time are options; a guarded link shows an "Open ..." link after the task instead of being followed; new `ask()`, `lock()`, `destroy()`, `onOpen`, `onPass`, a Tab trap inside the door and a `skip` switch for tests. 15 KB (5.2 KB gzipped). Real-browser check in Firefox 158 and ungoogled Chromium 155 covers 10 situations: early lift, sliding off the button, hold then drag, tap then tap, keyboard only, Escape and focus, a guarded link, touch, the open time running out, and a key press on a guarded button.

Tested in: Firefox 158, ungoogled Chromium 155 and WebKitGTK 2.52.6, one at a time, in a real browser (`tests/pieces-browser.js`, 2026-10-17; WebKitGTK 2.52.6 through `tools/webkit-driver`; key down/up and touch were sent as page events or the mouse). Not run: GNOME Web (Epiphany) 46.5, a phone.
