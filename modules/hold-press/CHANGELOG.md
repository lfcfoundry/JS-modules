# hold-press changelog

What changed in each version, newest first, in plain words. The full details (numbers, test runs, browsers) are kept privately by the maintainers. The API number goes up only when someone using an older copy could be affected.

## 1.1.0 · API 1 · 2026-10-17
- Buttons that are not being pressed no longer cost anything on every mouse or touch move, so pages with many buttons feel lighter.
- New option stops the browser from scrolling during a touch press.

## 1.0.0 · API 1 · 2026-10-16
- First labeled version. Nothing in the code changed.

## Before version labels

- Early October 2026: First version: hold-to-repeat for buttons that survives Android Chrome `pointercancel`.
- 2026-10-15: A hold now ends when its own finger lifts, even if a second finger is still on the screen.
