# speed-lab changelog

What changed in each version, newest first, in plain words. The full details (numbers, test runs, browsers) are kept privately by the maintainers. The API number goes up only when someone using an older copy could be affected.

## 1.1.1 · API 1 · 2026-10-17
- The report and table say FPS. Words only.

## 1.1.0 · API 1 · 2026-10-17
- Runs about a third faster, and a page that stops drawing can no longer hang the run.

## 1.0.0 · API 1 · 2026-10-17
- New tool, cut from Apple Press's phone speed test: one button runs a comparison on the device and writes the answer in plain sentences with a copyable table.
